A lightweight, responsive web application designed to track income and expenses in real-time. Built with a React frontend, powered by an Express/Node.js API server, and backed by a MongoDB database for persistent storage.

## Features

* **Real-Time Balance Updates:** Automatically calculates your running balance based on income (+) and expenses (-).
* **Dynamic Visuals:** Changes balance color dynamically (Green for positive balance, Red for negative balance).
* **Full Database Persistence:** Add or delete transactions safely; data remains intact even after refreshing the page.
* **Clean Web-Safe Typography:** Styled with a modern, scannable interface layout.
